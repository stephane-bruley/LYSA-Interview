# OPS-214 — Archive inactive customers

**Reporter:** Operations · **Priority:** medium

The customer list has grown a lot and it has become hard to work with. We would
like to clean it up.

Add a way to archive **inactive customers** in bulk from the customer list.

## Acceptance

- An operator can select several customers and archive them in one action.
- Archived customers no longer appear in the default list.
- The operator gets a summary of what was archived.
